# Octarine brand assets

From the Octarine design system (Claude Design). All text is outlined, so the SVGs need no fonts.

| File                      | Use                                                      |
| ------------------------- | -------------------------------------------------------- |
| `octarine-logo-light.svg` | Full lockup with a navy wordmark, for light backgrounds. |
| `octarine-logo-dark.svg`  | Full lockup with a white wordmark, for dark backgrounds. |
| `octarine-mark.svg`       | The octagon mark alone, for favicons and avatars.        |

The mark's gradient (#18f5fc → #26c5f5 → #4d7bf4 → #7938ea) is the source of the theme palettes.
Its cyan end is low-contrast on white, so prefer dark backgrounds at small sizes.

# Spacing & shape

## Spacing

Every spacing utility is a multiple of one base unit (`--spacing: {spacing}`), so `p-4` is
4 × {spacing}. Stick to the steps below to keep a consistent rhythm.

<div style={{ display: 'flex', flexDirection: 'column', gap: '0.5rem' }}>
  {steps.map((n) => (
    <div key={n} style={{ display: 'flex', alignItems: 'center', gap: '1rem' }}>
      <code style={{ ...label, width: '4rem' }}>{n}</code>
      <div
        style={{
          height: '1rem',
          width: `calc(var(--oct-spacing) * ${n})`,
          background: 'var(--oct-color-primary)',
          borderRadius: '2px',
        }}
      />
    </div>
  ))}
</div>

## Radius

<div style={{ display: 'flex', flexWrap: 'wrap', gap: '1.5rem' }}>
  {Object.keys(radius).map((name) => (
    <div key={name} style={{ textAlign: 'center' }}>
      <div
        style={{
          width: '5rem',
          height: '5rem',
          background: 'var(--oct-color-primary-subtle)',
          border: '1px solid var(--oct-color-primary)',
          borderRadius: `var(--oct-radius-${name})`,
        }}
      />
      <code style={label}>rounded-{name}</code>
    </div>
  ))}
</div>
